# Security

## Reporting a problem

Please report security and privacy problems privately, through [GitHub's private vulnerability reporting](https://github.com/0PrashantYadav0/rostery/security/advisories/new) for this repository. Do not open a public issue for them.

Say what you found, how to reproduce it, and what it lets someone do. You should hear back within a week.

## What counts

Anything that breaks a promise in [PRIVACY.md](PRIVACY.md), for example:

- History, a token or a key leaving the computer when the app did not say it would.
- A title, a name or a Provider's reply that can run script in the app or on a Share Site.
- A Share Site that holds something the person left out.
- A Provider CLI made to read files or run commands through Rostery.
- A token or key written anywhere but the system keychain.

## Supported versions

Only the latest release gets fixes.
